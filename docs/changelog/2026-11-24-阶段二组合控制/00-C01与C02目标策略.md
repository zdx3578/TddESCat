# C01 与 C02 的给定公开目标验收

2026-11-24，台北时间。实现分支为 `impl/2026-11-23-toolchain-bootstrap`，起点为 `fe4ab44b73d992c5962222625868762f34f7fc13`。验收使用 Python 3.12.9、Julia 1.12.6 和 Rust 1.90.0。

## 组合规划

Julia 从已发布的动作机制和完整的训练帧差异构造有界投影。每条边保留变化像素的原颜色、结果颜色、角色绑定和机制版本。执行前重验动作可用性、完整画面和绑定。收到响应后对照实际查询结果及下一帧，任一条件失效即撤回当前策略。若多个适用机制给出不同的预测画面，保留冲突并停止在该边上作确定规划。

目标由给定的主体颜色和标记颜色构成。求解器从本次公开画面绑定两者，并检验四邻接目标。实验室中的训练记录与目标环境分离，求解器只读取公开响应、已发布的机制及目标查询。测试裁判独立验证状态、动作和终点。
