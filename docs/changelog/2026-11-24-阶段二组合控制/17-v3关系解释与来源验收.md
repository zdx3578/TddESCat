# v3 关系解释和来源校验

当前学习入口使用 `tddescat.learn.v3`。公共事件继续使用 v1，E-Stitch 学习配置和运行会话各自使用 schema 2，表达节点使用 `typed-free-slots.v1`。定义身份由实际使用的算子语义、参数类型、返回类型和正文决定。已冻结的输入保存有序角色接口、语义构造与精确来源位置，Rust 和 Julia 分别复核。新签名加上未被定义使用的原语时，已发布定义可以复用。

关系解释器按完整共享列连接。投影保留产生同一答案的各个独立见证，否定使用已核实的有限域。动作前证据读取受截止位置约束。公开像素保留全部同色分量，移动、轮廓围合和计数各自按可检查的条件识别。公开机制绑定采用明确的颜色支持或轮廓内几何支持。
