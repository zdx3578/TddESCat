# 25 款公开游戏本地验收

`config/acceptance/arc_public25.toml` 锁定 25 个带版本的游戏 ID，默认读取相邻 `arc3wm` 仓库的 `offline_bundle/arc_agi3_public25_bundle`。离线包放在其他位置时，可在该配置中指定 `offline_bundle`。验收使用锁定的 `arc-agi 0.9.10` 和 `arcengine 0.9.3`，游戏源码以只读方式提供给本地官方 HTTP 服务。

```sh
.venv/bin/python -m tddesc_tools.run --config config/acceptance/arc_public25.toml
```

先核对离线清单、游戏版本、源码摘要和服务返回的游戏列表。Julia 从公开响应读取当前允许的动作，每款执行一次 `RESET` 和最多两次具体动作，保存原始响应的全部帧。服务关闭后，在无网络的进程中逐款回放两次，核对事件链、原始响应摘要、回放帧数和游标。第二次回放应新增零条事件。

`runs/public25-r01` 的 25 款全部通过。共确认 25 次 `RESET` 和 50 次动作，涵盖 `ACTION1` 至 `ACTION7`。75 条事件共含 165 帧，其中 13 条包含多帧，最长的单条响应有 42 帧。缺少离线包时，各款均报告 `BLOCKED`。

`public/acceptance.json` 记录逐款结论，`public/summary.json` 记录动作和帧数，`public/arc-source.json` 记录各游戏的版本和源码摘要。每款游戏目录保存请求、完整响应和回放游标。验收范围是本地环境启动、公开动作交互和证据回放。
