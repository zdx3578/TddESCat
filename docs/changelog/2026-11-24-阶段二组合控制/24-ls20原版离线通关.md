# ls20 原版离线通关

正式采集入口 `scripts/run.jl` 通过 `config/ls20_clear.toml` 启用指定原版 `ls20-9607627b` 的公开画面规划器。Python 启动官方离线 HTTP 环境，并把游戏源码和环境私有目录隔离在求解器之外。Julia 从当前画面和同局的已确认事件构建地图，估计移动标记的周期，搜索满足路形、图案、颜色和行动量的路线。它通过原有 `Recorder` 逐动作执行，核对公开反馈。

标记像素及其旋转、图案轮换、颜色轮换是通过公开动作实验确认后写入的游戏专用规则。每关的地图、目标位置、标记路线和实际动作序列在运行时求出。遮挡区域随移动补入地图，同一关重置后仍可使用此前公开可见的部分。

## 复跑

工具链就绪后，从仓库根目录运行。将 `--offline-bundle` 指向含 `offline_public_games_manifest.json` 和 `environment_files/` 的原版公开离线包。

```bash
.venv/bin/python scripts/clear_ls20.py \
  --offline-bundle /home/zdx/github/VSAHDC/arc3wm/offline_bundle/arc_agi3_public25_bundle
```

脚本创建新会话，等待关闭积分卡的回执，然后在独立网络命名空间中使用 `scripts/run.jl --replay` 核对已保存的响应。验收逐项检查七次关卡推进、末次原始事件的 `WIN` 和同一会话的积分卡。输出目录包含以下可核对的文件。

- `public/ls20-verification.json` 保存七次推进的事件标识、回执摘要和累计方向动作数。
- `public/commands/`、`public/events/` 和 `public/blobs/` 保存命令、完整回执和帧。动作预测与核对分别见 `public/predictions/` 和 `public/pattern-maze/`。
- `public/replay.json` 保存回放游标和逐帧差异。环境来源、隔离探针和各产物摘要分别见 `public/arc-source.json`、`public/solver-isolation.json`、`public/artifact-index.json`。

两次正式实测 `runs/ls20-clear-r01`、`runs/ls20-clear-r02` 均从新会话取得 `WIN`，完成全部 7 关。每次执行 433 次方向动作和 2 次关内重置，连同首次 `RESET` 保存 436 条环境事件和 847 帧。关卡推进的累计方向动作数依次为 15、60、103、146、196、310、433。第二次验收核对到离线积分卡的 435 次动作，包含两次关内重置，得分为 96.316。
