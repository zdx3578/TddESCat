# 学习尾批、恢复与实验服务

学习入口为每条已确认的公共动作登记独立义务。Julia 在批次或会话结束时冻结待处理事件，使用原 E-Stitch worker 学习，并记录事件、任务、解释和终止结果。相同响应摘要仍可对应多次干预。构造不完整的事件保留重解释标记。冻结评估的事件进入评估目录，版本和发布指针在评估前后核对。

训练按服务轮次选择当前可用的公开动作。ACTION6 的 4,096 个坐标都可以进入义务列表，视觉绑定候选优先。每次发送前重验动作是否可用，仅确认反馈满足服务义务。当前轮进度、已服务动作和动作不可用的原因都可以回读。轮次队列首先覆盖公开动作与坐标，跨布局的角色及关系条件义务在后续联想阶段接入。

离线恢复读取已保存命令和响应，补回遗漏登记，并验证已有完整 worker 结果。恢复过程在无网络的求解器中运行。使用采集时的配置、学习策略和二进制身份，保持公开命令账本一致。
