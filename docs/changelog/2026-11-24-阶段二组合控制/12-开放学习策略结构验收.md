# 开放学习策略结构验收

正式学习策略已切换到 `config/stitch.toml` 的 schema 2。Julia 冻结策略原文与摘要，Python 复核并监管进程，Rust 用同一策略完成搜索。公共事件协议继续沿用 v1，活动学习协议为 `tddescat.learn.v2`。默认 `max_arity=1000`，完成条件为当前冻结问题的已验证单步压缩固定点。学习步数、轮次、文件大小和库定义数量的旧截止已从运行入口删除。进程仍由 cgroup v2 隔离，未设置的内存值由实际父组和机器资源决定。

| 检查 | 本机结果 |
| --- | --- |
| 两端编解码 | 0、1、8、9、19、64、65、1000 参数均通过。额外绑定、非法索引或类型仍会被拒绝。 |
| 真实最佳优先搜索 | 分别发现 4、6、10、12、15、19 参数定义，经独立展开、成本核对和发布。19 参数为 `449 → 217`，含终止轮共弹出 113,866 次。 |
| 持续增长 | 24 个独立定义，第 25 个搜索轮确认无正收益。2／4／8／20／24 个定义时的总费用分别为 745／721／673／529／481，初始值为 769。 |
| 依赖续学 | 三批分别搜索、签收和发布。后批引用前批稳定定义，最终依赖深度为 3。移除基础定义会使依赖库校验失败。 |
| 输入口径 | 4,537 条程序、31,759 个语法发生位置、6,333,028 字节来源文件完整签收，复核了最后一条程序。 |
| 离线和在线匹配 | 对同一条官方离线 HTTP 事件，两处均保留 1,157 个候选角色的检查范围、资源减 1 的合法见证和未决对象对应。输入解释不完整时任务没有签发固定点。 |
| 原子性和错误处理 | 验证首轮提交前取消、完整轮之后取消、写临时目录时取消、资源失败及损坏检查点。完整轮保留并可验证。 |

首个 19 参数试跑已保存正收益轮。第二轮搜索内存持续增长后，发送 `SIGTERM` 并保留唯一完整轮。新版将本轮已知基线费用用于原有精确下界比较，只有不能严格降本的分支会被剪枝。复跑的 19 参数用例以 `verified_compression_fixed_point` 结束，Rust 托管分配峰值约 1.50 GiB。

原生单轮参照使用同一锁定工作区的 `egg-stitch` 命令与 `op-children` 语言。Furniture 得到 15 参数及 `42,936 → 22,960`，Wheels 得到 19 参数及 `35,427 → 22,711`。这些数值来自本机运行的构造与搜索记录。

```sh
cargo build --release --offline --locked -p tddesc-stitch -p egg-stitch
.venv/bin/python -m tddesc_tools.run --config config/acceptance/stitch_bridge.toml
.venv/bin/python -m tddesc_tools.run --config config/acceptance/stitch_reference.toml
```

结构验收在 `runs/estitch-open-structure-r03`，原生参照在 `runs/estitch-open-native-r01`。`open-structure.json`、`learning-summary.json` 和各次 `result.json` 记录输入、逐轮费用、来源证明、依赖、停止原因及精确检查点。阶段一及组合控制由各自验收入口保存独立报告。
