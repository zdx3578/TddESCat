# C03 滚动后绑定与撤销修订

求解器接收公开的目标颜色、距离和信号条件。起始画面中目标不可绑定时，先执行公开探索动作。新的画面使目标可见后，使用从公开训练事件学到的选择、移动与撤销机制，冻结动作及逐步预测。独立裁判核对有限状态转移，再用官方离线 HTTP 接口核对完整响应。

| 对照 | 验收条件 |
| --- | --- |
| 滚动与局部撤销 | 滚动前的坐标 `(54, 24)` 在新画面上失效。求解器执行 `ACTION1 → ACTION6(50, 24) → ACTION3 → ACTION7`。移动消耗资源，撤销恢复位置并触发公开信号，资源仍为 `0`。最后确认 `WIN`。 |
| 改变动作顺序 | 在同一公开画面执行点击再移动或移动再点击，得到不同末帧，资源分别为 `0` 和 `1`。 |
| 错误绑定 | 两个同色角色重叠时，点击反馈反驳选中预测。撤回依赖该绑定的关系、条件和待执行动作，保留受支持的结构定义。读取反例后重新选动作。 |
| 目标不可见 | 更窄的视口在探索后仍未露出目标，目标状态为 `unknown`。 |
