## 4. 需要写进正式规格的理论边界

### 4.1 闭包与关系概念学习

Formal Concept Analysis（形式概念分析，FCA）的精确闭包需固定对象域、属性域及完整关联关系。开放世界中的未观察不能当false；只能对有完整性证书的切片做精确闭包，对其他范围保留上下界与未知。

Relational Concept Analysis（关系概念分析，RCA）可以从对象间关系生成关系属性，但不自动给出因果解释。Euzenat的2025论文进一步说明循环依赖下有多个可接受不动点，标准RCA给出其中最小者；不能声称“执行闭包就得到唯一正确世界概念”。本项目应采用证据扎根、有限当前域的明确语义；新候选定义进入下一次可续生成，不能要求每次行动前构造全部概念格。

多角色作用在共同关系层保留n元变量及共享绑定。不得把三元事件随意拆为独立二元边后丢失同一次作用的关联。

### 4.2 抽象精化与黑盒环境

Counterexample-Guided Abstraction Refinement（反例引导抽象精化，CEGAR）为“抽象计划不能具体化时恢复必要区分”提供方法。经典结果通常给定具体转移系统。本项目只有公开回执，因此必须区分：

1. 完整有限模型内约束冲突：可以给出该模型/域内反例。
2. 不完整知识导致无绑定：结论是未知，产生辨别或可达性义务。
3. 真实行动结果违反确定预测：撤回适用资格，保留原始反例并修订。
4. 随机模型的不同结果：不自动成为逻辑冲突，更不自动证明隐藏变量。

Predictive State Representation（预测状态表示，PSR）的测试预测思想用于历史区分；当前有限样本的谱秩或状态合并不能自动保证真实环境的完整可识别性。

### 4.3 控制保持比各步存在见证更强

必须保持整条路径共享中间状态、对象角色、历史及观察分支。存在一条模型内轨迹只支持可能性；保证控制还要求考虑所有合法后继，以及先行动后观察的顺序。未知后继不能被过滤后冒充必达。

Konidaris等人的技能符号理论强调动作前提和效果对规划表示的重要性；它不是任意黑盒环境自动发现全部技能或高置信通关的定理。

### 4.4 三种最小性与实际代价

语义简化、因果角色删减、代数规范化分别验收。只有在声明查询、作用域及具体删减集合内通过检查，才能说“在这些条件下未发现可删部分”。不能从有限支持样本宣称全局最小因果单元。

Factor Rank（因子秩）产生的有理数基函数不天然具备对象或概率含义。变量树调整须计入转换、精确系数、构建、维护和跨语言代价；未知收益不伪装为优化结论。
