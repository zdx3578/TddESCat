## 1. 核心裁决：保留 V13 三个认知过程、两个横向基础

01 已补齐唯一知识定义、作用类型、随机来源、查询保持/细化、范围依赖和版本发布。不能把这些作为本轮新发现。进一步缺口是：给定这些接口，怎样让知识生成、压缩、控制在同一证据驱动算法内互相提出新问题、生成新变量、检验并修订，而不仅是模块互调。

采用共同可执行关系定义，沿用 DefinitionRef/ScopeRef/SnapshotRef 与现有知识所有者。静态关系、带角色转移、程序关系都用有类型的有限关系/函数表达；有限域随实际事件增长。对象、概念、机制、程序是不同语义层，Grid64/位集、Galley/Finch、Factor Rank/Algebraic Tree Decision Diagram（代数树决策图，ATDD）、Probabilistic Circuits（概率电路，PC）、E-Stitch 是计算和发现能力，不各建知识库。

三个最小性不可等同：语义最小指声明用途下无需更多描述；动作—对象最小因果单元指特定可干预范围内不可删去的角色、条件、历史和效果；代数最小指固定函数与分区中的线性冗余。共同接口而非强制共享分解：代数因子提出可解释候选，语义定义产生新计算结构，环境实验区分因果候选。纯计算因子可以没有独立可干预含义。属性语义也不必都有因果功能。

## 3. 多维偏序：从检索变为联合抽象生成

不同维度的边是不同的有类型关系。集合包含、条件蕴含（按等价取商后）、机制细化（含角色/动作/效果映射）、时间前缀等可分别组织偏序；重叠、统计相关、证明依赖、计算树边不等同为抽象关系。仅在接口、作用域、保留查询及映射都对齐时组合语义抽象见证，不能沿无类型边传递推断。

共同计算沿用 Functional Aggregate Query（函数聚合查询）：H(X,Z)=⊕_Y F(X,Y)⊗G(Y,Z)。F/G 是类型化关系，X/Z 是保留变量，Y 是共享消去变量。布尔存在投影、计数、概率边缘化、代价优化分别使用合法代数；不能交换不可交换的消元顺序。
以对象结构相似、作用响应相似、空间条件和历史差异联合查询，提出“共同角色在上下文 C 下具有共同效果”候选。形式概念分析、关系概念分析、反统一分别提供闭包、跨对象关系属性和参数化表达；未知不能直接补成假，闭包只在声明完整切片上作精确结论，其他结论保留未知/候选资格。索引返回候选、相关证据与范围；语义判定确认关系。

新概念不仅须定义，还要能够回答至少一个具体的预测、区分、绑定、组合或目标查询。目标回归能提出所缺条件，因子分解能提出共享函数，残差能提出缺失角色；全部进入同一候选生成与验收流程。无需新建六份知识库或另一调度器。

## 4. 最关键的新算法：任务/预测义务驱动的联合抽象与精化

已有 01 的抽象合同回答“如何验收”，这里强化“如何产生抽象”。借鉴 Counterexample-Guided Abstraction Refinement（反例引导抽象精化，CEGAR）和 Predictive State Representation（预测状态表示，PSR）。传统 CEGAR 有已知具体模型；ARC3 只能访问公开动作回执，不能把环境当可查询全部真实状态的裁判。PSR 以未来测试的预测作为状态，测试的发现与预测学习是独立任务。

共同驱动信号：原始变化未解释、同一抽象状态下对齐动作响应有区别、抽象计划无法具体绑定、已知机制在新域失效、公共目标回归需要新条件、重复结构/计算发现可复用定义。

伪代码（接口名表示拟统一算法，不冒充已存在函数）：

    on_confirmed_public_event(event):
        persist_event_and_all_public_frames(event)
        publish_exact_deltas_and_invalidation()
        compare_prior_frozen_predictions_to_receipt()
        add_obligations(residuals, ambiguity, response_conflict,
                        uncovered_actions, unmet_goal_queries)
        find_relevant_witnesses_and_affected_definitions()
        propose_by_generic_operations()
        verify_and_publish_independent_complete_units()
        reuse_unchanged_query_plans_and_refresh_affected_views()
        select_one_legal_public_action_and_freeze_prediction()

    propose_by_generic_operations():
        collect comparable role/context/history/effect instances
        find common structures and distinguishing differences
        generate typed candidates from join, projection, closure,
            decomposition, composition, anti_unification,
            parameterization, bounded-domain symbolic constraints,
            history-response tests, and factor structure
        retain alternatives and unresolved evidence obligations
        check type, scope, executable interpretation and query preservation
        distinguish mathematical exactness, empirical support, unknown
        if competing candidates are not distinguished:
            propose reachable public action/sequence that separates predictions
        publish only appropriate qualification; do not force one winner

关键：生成器不按游戏名、预设机制名派发；使用有限公开事实中的通用原语及可组合表达。搜索必须可续，资源不足不能丢失前沿或标记完成，配置采用文件、不得以压低默认参数或删历史换取速度。存在不可识别、不可达或无限候选时如实报告。

### 4.1 从响应发现必要状态变量

对历史 h 和未来测试 τ（可公开执行的动作/观察序列），记录 p(τ|h) 的模型预测及真实证据；未尝试不填 0。选择当前抽象相同、角色与动作可比但结果有区别的历史对；检查观测完整性、角色解释、随机波动。通过多维索引找可区分的结构/历史谓词，联合构造候选并重新检验旧证据。若候选一致，挑可达且预测分歧的公开实验。新变量须对消费者有增益。确定性对立回执可否定相应确定预测；随机条件下需复核分布/不确定性，不因一条差异断言隐藏状态。真实无法回到相同上下文时保留义务，不强行 RESET 假设同初始状态。

### 4.2 从计划失败产生语义精化

对计划的每一步转移 T_i(s_i,a_i,s_{i+1})，联合所有中间状态与对象角色绑定、动作合法性、终止/必要观测及最终目标。不能分别为每步找不同见证后宣称全路径可达。
若模型内联合绑定为空且该有限域完整，则分析最早无法继续的接口与冲突约束，精化抽象变量、角色或中间条件；若信息不完整则未知，产生实验义务。存在联合见证只是模型内可能性，不是环境成功保证。对分支/随机结果保持“先观测再选择”与“先选择再观测”的顺序差别。滚动执行每个真实动作并核验，而非一次提交整条未验证计划。

合成反例：抽象动作 P 结束时对象在位置甲或乙；动作 Q 只接受位置乙；P 在当前绑定下只到甲。若高层省略位置，两段各有独立成功见证却不能复合。应从不可满足的中间连接恢复必要位置/角色条件，而不把 P/Q 全局废弃。如果真实 P 还能随机到乙，需保留概率及未知，不能宣称任一绑定均成功。

## 5. 七类持续压缩成为共同的结构更新过程

原始数据/关系/代数/语义/程序/动态状态/搜索七种压缩保留不同正确性责任。原始数据无损；关系和精确计算保持声明域答案；语义及状态压缩保持声明查询、动作与目标行为；程序压缩保持必要轨迹；搜索压缩需有严格蕴含/等价/作用域等排除依据。失败样本不能无条件排除相似但未证伪假设。

双向路线：共享因子、公共查询、程序片段 → 提出带角色的定义 → 对齐内涵、外延及行动效果 → 新语义接口缩小查询变量范围 → 重新选择连接/局部变量树/公共子表达式 → 以同域语义验证并测总成本。反例反向拆分必要区分，再局部重编译。禁止把因子秩/概率置信/语义抽象深度混成一个偏序或一个万能分数。全局最优变量树不是已有能力；从当前结构、实际查询负载和依赖出发尝试局部变换，记录转换代价与系数位长，尤其避免全域真值表膨胀。

精确物理表示是否采用由构建、重复查询、增量更新、跨语言传输、内存及失效重建的实际总成本决定；直接位集/稀疏关系和编译视图都是正式、可验证执行计划，而非失效旧逻辑的兼容 fallback。纯物理重组不改变知识版本的语义或证据资格；经验反例必须使受影响预测和动作资格失效，不能继续使用旧结果。

## 6. 动作—对象最小因果单元的闭合覆盖

每个义务表达公开动作及参数域、对象角色组合、适用上下文/历史、预期直接/延迟/联合效果及相关不变部分、竞争解释、证据和剩余实验。覆盖不是全坐标计数，不是动作 ID 次数，也不是压缩节点数。参数可按已验证作用等价类因子化，但未经确认的坐标或对象角色范围必须显式未覆盖。ACTION1–7 以公开 available_actions 为准，ACTION6 保存合法坐标映射，ACTION7 与 RESET 仍区分。所有数据 strict public API；不读取 debug/private metadata。

区分至少四个独立结论：动作域覆盖、作用解释覆盖、因果区分充分度、实际控制稳定性。记录已验证条件范围、正/反例、无法区分/不可达、未检查效果、失败后再选择是否改变。统计置信、对象身份确定性、机制适用性、效果概率和因果识别资格不混为一项。一个回执的多个帧或重复推导不是独立实验。样本不足不得声称高置信。动作干预的可识别范围受公开观测及可控性限制，不宣称全部反事实已识别。

选择动作：所有可合法执行的候选共同说明目标推进、预测区分价值、覆盖义务、失败/进展风险以及执行条件，避免单纯按来源固定排序。优先兼具目标推进与区分价值的行动；不能估计则保留未知与探索义务，不凭空计算概率。单一仲裁器派发前复核最新快照与所有作用/范围资格，动作后用真实结果更新同一义务。通关之后仍按任务定义处理未验证知识，不把赢当作因果全覆盖。

## 7. 实施：纳入已有 M1/M2，不另设五个里程碑

M1（05/06/07/08 与 13 的 M1.1–M1.4）：完善统一的公开事件/全帧关系、类型化查询和范围依赖；从 Grounding 到共同作用角色、实验义务、正向预测与反向用途、真实派发、修订再到下一动作。替换依赖 translation 的绑定及单区域候选的固定语义限制；先建立通用分解/组合/对应的核心路径与可续前沿。对同一个机制条件使用唯一查询，验证多消费者共享及无效结果不会流入动作。复用 05/06 现有关系语义、Galley/Finch、精确 ATDD 和 cvc5 适配；不另建知识库。
M1 验收：
- 同动作作用多对象、非连通共同角色、全部回执帧及延迟效应；原始证据可独立复算。
- 新事实改变空绑定/负条件，预测/控制/实验同时失效；无关事实不全局重建。
- 新证据使原机制假设撤回，必要区分进入下一次实际决策；记录派发前预测和依据。
- 独立检查 ACTION1–7 合法域、ACTION6 参数及覆盖未完成项，统一公开入口。
M2（07/08/13 的 M2.1–M2.4）：共同候选生成器扩展为目标/残差/反例/复用驱动的变量发明；关系闭包、反统一、CirKit 统计结构、历史响应和 E-Stitch 程序共享接到同一抽象合同。加入全路径绑定检查、具体失败精化、共同作用与目标回归；多维索引从查找升级为联合候选生成。因子压缩与语义结构双向反馈；所有新概念需实际消费者、作用域及精化路径。沿用已有工作包，不新增并行调度器，不强制引入额外依赖。
M2 验收：
- 同画面异历史、关系组合条件、共享多区域功能、联合效应等留出合成任务；不注入正确机制名。由公开证据发现必要区分，新反例后局部拆分。
- 两段各自有见证但联合绑定为空的假计划；确认精化中间接口而非错误派发。未知不误报不可达。
- 反统一/E-Stitch 产生定义被新实例真实绑定，分支/循环必要观察与退出条件核验，失败后重新选择。
- 比较同段轨迹/同输入语义下独立求值与共享增量求值：查询次数、编译时间、更新时间、内存、桥接数据量、首个与后续行动延迟。单独记录认知能力：未解释变化、必要条件区分、新实例复用、真实反馈改变下一步。使用相同公开游戏版本和可比过程，不以不同随机游戏普通分差作为主要结论。

## 8. 补充研究依据

- Clarke 等，Counterexample-Guided Abstraction Refinement for Symbolic Model Checking：https://doi.org/10.1184/R1/6604547 。可参考局部精化和虚假反例，已知具体模型前提不同于公开黑盒环境。
- Seipp/Helmert，Counterexample-Guided Cartesian Abstraction Refinement：https://cdn.aaai.org/ojs/13605/13605-40-17123-1-2-20201228.pdf 。规划抽象保留路径而抽象计划可能无法具体化。
- Littman/Sutton/Singh，Predictive Representations of State：https://proceedings.neurips.cc/paper_files/paper/2001/hash/1e4d36177d71bbb3558e43af9577d70e-Abstract.html 。基于未来动作条件观察预测表示状态。
- Singh 等，Learning Predictive State Representations：https://mlanthology.org/icml/2003/singh2003icml-learning/ 。发现测试与预测学习不同；没有直接解决 ARC3 开放对象变量发明。
