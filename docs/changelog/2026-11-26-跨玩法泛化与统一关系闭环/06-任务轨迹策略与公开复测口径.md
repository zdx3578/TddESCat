# 任务轨迹策略与公开复测口径

公开关系语料从已确认的任务前后角色、动作可用性变化和具有对照的延迟作用建立依赖。顺序候选引用实际依赖，分支候选要求共同入口和不同后续任务的公开区分条件，重复候选要求连续经历及观测到的退出条件和次数范围。未解释的像素变化继续作为证据缺口记录。

策略候选以带类型的表达提交原 E-Stitch 搜索。发布时校验搜索输入和展开，逐个复核源轨迹中的动作、角色共享及可见条件。决策记录实际用到的定义、发布时间和分支。解释器按新公开帧重验任务绑定及结果，反例或公开失败会撤回未执行的后续步骤。

复用序列程序按经过组合核验的关系产出加入索引。目标回归可先召回这些程序，再在当前公开帧验证动作、绑定、依赖和投影。策略实际动作与同一时点的完整仲裁选择同时保存，便于核查控制贡献。

验收入口为 `config/acceptance/relation_policies.toml`。此处的顺序、分支和重复用例来自本地隔离的 ARC SDK 受控场景。原版 24 款复测由 `scripts/evaluate_public24.py` 协调，分开核对回执与回放、阶段内最高进度、终态进度、计分卡 WIN、失败重开，以及已用策略实际改变的动作。批次使用 `config/autonomous_public.toml` 和 `config/stitch.toml`。
