# 统一作用任务与失败续学

`OnlineSession` 将点击、移动接触和无坐标操作提交到同一个公开关系入口。每条回执关联前帧、具体作用、角色绑定、尝试编号、未知变化及公开终态。局部作用是否成立和关卡是否推进分别记录。原有跨关点击晋级条件继续由跨关证据验证。

作用候选和正式核验共用 `JointMechanism`。点击新位置时匹配被点击角色、受影响角色的相对位置及可核验的局部变化。未验证的迁移保留具体条件预测，两个独立角色的同向见证可支持同关迁移，矛盾结果会撤回相应预测。已观测的同一对象移动后保持角色对应。

同一仲裁入口接收计划续步、具体作用、延迟效果实验和坐标覆盖。未见画面变化的回执可作为下一步实验的历史条件。远端公开状态改变时，曾经无作用的同一对象可以重开实验。遇到公开失败后，按合法 RESET 回执更新尝试和角色绑定，保留已经观察的作用及失败前史。失败归因保留为未知，下一尝试可改变首步以区分候选解释。

| 公开接口验收 | 观察结果 |
|---|---|
| 延迟作用 | 第一动作公开帧保持一致，第二动作引用前一回执并引起具体改色 |
| 远端条件与混合动作 | 原位置点击无效果，无坐标动作改变远端条件，随后重探原位置并晋级 |
| 作用方向 | 新角色原先预测向右 4 像素，公开帧显示向左 4 像素，预测被撤回 |
| 失败续学 | 第三实例的局部改色得到支持，同一回执为 GAME_OVER，随后 RESET 并改变首步取得 WIN |

执行验收使用 `config/acceptance/unified_relations.toml`。四类场景由隔离的本地 ARC SDK 提供，独立裁判核对原始回执及事前引用。24 款原版游戏的成绩在第二个里程碑完成后单独复测。
