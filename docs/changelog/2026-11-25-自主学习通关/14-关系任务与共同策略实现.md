# 关系任务与共同策略实现

Julia 从已确认的接触分别记录进入、对象变化、晋级和获胜。主体遮挡目标时，完成义务保持未决。离开后能看清目标确实变化，才允许更新本关候选集合。再次看见原目标时，义务可以重开。联合晋级条件用同一次公开尝试的事件身份连接特征，未见组合保持未知。

规划器把学得的晋级关系作为目标，用当前像素重新绑定接触对象，记录可建立目标的机制及其前置条件。已有程序可以建立缺失前提，后续动作逐步核对新增条件和暂时失效的目标。条件未知时，区分实验须有相关预测和先前反例。

计量模型从公开读数学习动作相关扣减、部分补给和重复补给。投影模型分别核验局部效果和整帧适用范围，支持角色相对坐标及联合条件。独立验收从回执前缀重建条件读集，重新核对投影与实际画面。

条件策略语料来自已闭环的公开任务经历。编译器先检查不同重复次数、分支结果和目标集合的下降证据，再由真实 E-Stitch 搜索共享正文。`PolicyBranch` 在当前关系上选择任务，`PolicyRepeat` 每次要求重新确认有限候选域确实缩小，`PolicyStop` 等待公开晋级。发布后的调用保存搜索证明、开始可用的回执及当前绑定。公开反例撤回当前策略并传给下一次规划。

## 表示假设

- 空间候选仍以像素支持、可见组件、相对位移和局部图案提出。路径搜索会使用已测位移、计量和通行关系。
- 共同策略首个模型使用有限的可见接触候选域。它能在新位置、颜色和动作编号下重新绑定。未见读数需要区分实验，目标集合扩张会使当前重复证书失效。
- Julia 核对对象、条件和可用时点，并对搜索结果签收。Rust E-Stitch 搜索共享结构。Python 运行隔离的官方本地接口，并独立验收公开证据。

## 验收入口

| 验收 | 入口 | 所核对的行为 |
|---|---|---|
| 关系任务 | `config/acceptance/learned_relationships.toml` | 建立缺失前提、未知条件实验、暂时失效后恢复 |
| 程序投影 | `config/acceptance/projected_program.toml` | 两步程序重绑相对条件，消费非空补丁，独立拒绝错绑定和漏读集 |
| 冻结策略 | `tests/bench/check_learned_policy.py` | 从指定公开训练前缀真实搜索，冻结正文后验证不同布局、数量和反例后的动作 |
| 原版同局 | `config/acceptance/autonomous_offline.toml` | 同会话推进、关系目标实际建立、已发布策略实际消费及最终成绩卡 |
| 其他 24 款原版游戏 | `scripts/evaluate_public24.py` | 使用同一构建分别冷启动，保存动作、学习消费、进度、终态及离线回放 |
