# 公开反馈驱动的空间学习

`planning.autonomous` 从空白知识开始。Agent 从同向移动的相邻像素支持中提出角色，用公开反馈核对位移和动作编号。它随后沿已确认的路线寻找有新信息的动作，比较画面中不同尺度的图形，提出目标条件。图形变换、补给和移动标记的周期由动作前后画面和回执约束。计划每执行一步都要重新绑定，位置、图形或资源发生变化会触发重算。

训练批次仍由正式入口交给 E-Stitch。视觉计划引用实际发生的早期事件，回放逐一核验这些引用的时序。完整通关验收需要原版环境在同一会话中依次增加全部关卡，返回 `WIN`，并用相同会话的积分卡和断网回放确认结果。

```bash
.venv/bin/python -m tddesc_tools.run --config config/acceptance/autonomous_offline.toml
```

当前对照记录见 `runs/autonomous-ls20-baseline-r01`。旧入口的 35 次方向动作取得了结构定义消费证据，关卡进度为 0。接入空间实验和图形条件后，`runs/autonomous-ls20-control-r06` 记录到前四关的实际递增。后续冷启动的空间学习内核实验 `runs/autonomous-ls20-kernel-r14` 在同一会话推进至六关，并保存了末关的局部视野实验。

末关观测暴露了被截断图案引发的目标歧义。程序使用完整对比轮廓签收目标图案，并用已经走通的区域、可见性变化和学到的行动量组织新的观察路线。整体通关以正式入口输出的 `public/autonomous-verification.json` 为准。
