# 公开反馈驱动的空间学习

`planning.autonomous` 从空白知识开始。Agent 从同向移动的相邻像素支持中提出角色，用公开反馈核对位移和动作编号。它随后沿已确认的路线寻找有新信息的动作，从画面独立提出可接触位置和候选观测窗口，再比较接触前的公开特征。图形变换、补给和移动标记的周期由动作前后画面和回执约束。计划每执行一步都要重新绑定，位置、图形或资源发生变化会触发重算。

训练批次仍由正式入口交给 E-Stitch。视觉计划引用实际发生的早期事件，回放逐一核验这些引用的时序。完整通关验收需要原版环境在同一会话中依次增加全部关卡，返回 `WIN`，并用相同会话的积分卡和断网回放确认结果。

```bash
.venv/bin/python -m tddesc_tools.run --config config/acceptance/autonomous_offline.toml
```

当前对照记录见 `runs/autonomous-ls20-baseline-r01`。旧入口的 35 次方向动作取得了结构定义消费证据，关卡进度为 0。接入空间实验和图形条件后，`runs/autonomous-ls20-control-r06` 记录到前四关的实际递增。后续冷启动的空间学习内核实验 `runs/autonomous-ls20-kernel-r14` 在同一会话推进至六关，并保存了末关的局部视野实验。

末关观测暴露了被截断图案引发的目标歧义。程序使用完整对比轮廓签收目标图案，并用已经走通的区域、可见性变化和学到的行动量组织新的观察路线。整体通关以正式入口输出的 `public/autonomous-verification.json` 为准。

## 从接触回执学习条件

候选位置来自完整对比轮廓和经实际位移测出的坐标格。初始观测窗口从格外的图案中选择。关系语法比较范围、完整支持、颜色和像素数，允许相等或不等及其合取。程序按每次真实尝试的受阻、进入或关卡推进回执保留兼容条件。不同条件仍有分歧时继续实验。已经观察到变化、但当前输入未知的效果，可以按其对待验证条件的影响安排试探。

每次候选接触的预测记录冻结选择时点、像素窗口和训练回执。独立核对从原始帧重建特征、角色落点和候选条件。推进一关须能在响应序列中看到角色落到对应位置，且回执明确推进关卡。第一次动作作为冷启动探测单独记录；其后的空间决策须引用已发生的动作证据。

内核诊断 `runs/contact-induction-kernel-r04` 使用原版离线 HTTP，从新会话依次通过 7 关，得到 `WIN`。诊断使用同一学习与控制内核。包含真实结构搜索、逐动作证据与独立回放的完整验收结果由正式入口单独记录。
