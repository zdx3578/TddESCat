# ls20 自主学习的先验设置与架构实际作用

日期为 2026 年 11 月 25 日，台北时间。本文记录提交 `16deaaaa3f9859022b4655376ca1620cc030f363` 上的正式实验。运行产物保存在 `TddESCat-goal-induction` 工作树下的 `runs/contact-induction-formal-r01`。评估对象是第三代通用人工智能抽象与推理语料库（Abstraction and Reasoning Corpus for Artificial General Intelligence 3，ARC-AGI-3）原版游戏 `ls20-9607627b`。Agent 指读取公开观测、发出动作并更新自身模型的智能体。

## 输入和运行设置

- Python 在隔离进程中启动原版离线环境。环境对求解器提供超文本传输协议（Hypertext Transfer Protocol，HTTP）公共接口。官方工具包版本为 `0.9.10`，环境引擎版本为 `0.9.3`。游戏源文件的 256 位安全哈希（Secure Hash Algorithm 256-bit，SHA-256）为 `298c810da2850d557c95d92a2cbd846df29a45d7134e20888617bedf5dafcd92`。
- 求解器从空知识库和新会话开始。输入限于公开帧、动作域、自己提交的动作及回执。配置中的游戏编号用于选择环境。每次当前关重置保留已确认的关卡进度和自己在本次会话学到的知识。
- `planning.autonomous = true` 启用自主空间学习。公共命令上限为 900，同一会话只容许一个未确认的动作。每批 8 条确认动作进入后台结构学习，结束时补齐尾批，学习工作进程由 Linux 控制组执行 6 吉比字节（gibibyte，GiB）的内存限额。
- E-Stitch 使用 `config/stitch.toml` 的 schema 2 策略，选择最佳优先搜索、`max_arity = 1000`，以及经过验证的压缩不动点作为学习终止条件。1000 是参数个数的许可边界。每批搜索实际完成的轮次和接受的定义来自该批 `output/learning-summary.json`。 [运行配置](../../../config/autonomous_public.toml) · [搜索策略](../../../config/stitch.toml) · [隔离实现](../../../python/src/tddesc_tools/isolation.py)

## 先验设置及其对应的学习结果

这套视觉候选是在调试 ls20 的公开反馈时选定的，属于对这类像素谜题的归纳偏好。先验决定哪些量值得观测、怎样生成候选和如何安排实验。具体角色、接触效果以及条件是否成立由当前会话的公开数据决定。

| 环节 | 代码预置的表示或选择原则 | 运行中由回执确定的内容 |
|---|---|---|
| 受控对象与地图 | 将同向移动且相邻的像素支持合成候选，优先使用可唯一重绑定的完整支持。根据已测位移的最大公约数提出坐标格。用落点颜色频数提出常见地面，以已走通的边和局部像素支持预测空间可达性 | 实际受控的像素集合、动作编号和位移的对应、阻挡位置，以及在一次多帧动作中首次落点与最终落点的差异 |
| 图案与接触位置 | 将单一前景色及统一背景中的规则像素块表示为归一化尺寸、支持掩码、颜色和像素数。完整对比轮廓且与坐标格对齐的小图案生成接触候选。初始上下文使用坐标格外面积最大的可读图案窗口 | 当前帧的窗口、接触位置和具体图案。读取候选窗口与落点来自保存的像素证据 |
| 接触条件 | 在范围、完整像素支持、颜色、像素数四项上枚举相等、不等或省略，构成 81 个合取候选。共用这套关系语法跨当前会话的关卡更新。样本不足或候选有分歧时保留未知 | 颜色保持相同而支持改变时受阻，支持保持相同而颜色改变时也受阻，随后相合的状态实际进入或推进。由这些对照收敛到同时要求完整支持和颜色相同的规则族 |
| 图案变换 | 优先用已见输入输出对。未知输入尝试从矩形轴交换、轴翻转、同形换色映射和方向等变关系中找一致的候选 | 哪种接触实际改变形状或颜色、变化如何复用，以及同一位置的后续动作是否产生新效果 |
| 资源 | 将细长、窄于受控对象的矩形作为计数候选。唯一观测到下降的候选进入模型。将首次观测到的下降量和几何容量用于规划，根据实测补给标记维护本次尝试已用位置 | 哪个公开区域会下降、动作消耗量、补给出现在哪类局部图案、哪些补给已被本次尝试使用 |
| 遮挡与时间 | 保存早先可见的局部地图。随受控角色移动推进时钟，枚举与公共目击一致且逐格相邻的循环轨迹。资源耗尽时以学到的内容变化决定是否再试 | 从哪个位置能够看清局部结构、哪些观测暂时被遮挡、移动标记的相位和位置，以及哪次新证据值得重新尝试 |
| 规划与实验 | 在位置、图案值、剩余资源、已用补给及相位组成的状态上搜索。用已确认效果模拟后续，优先尝试可能改变尚未满足的条件且当前输入未验证的效果。每次实际提交前重验接续计划 | 实际路径、在哪些地方反复试验、何时改变图案再接触、何时转向取证或使用补给 |

图案窗口搜索的边长从 4 到受控对象较长边的两倍加 1，归一化支持使用最多 64 个位置。资源候选的长短边之比至少为 4，补给后的规划上限取候选矩形长边。时序模型至少需要 4 次公开目击才枚举循环。

81 个候选包含无条件通过、相等、不等及必要的组合。首个接触预测为 `unknown`。单个方向的反例只排除与该反例矛盾的假设。四种保留写法中的范围和像素数比较由完整支持相同蕴含，所以在当前表示下与“完整支持和颜色相同”等价。库内测试还用相反的颜色条件验证了同一学习器会调换所选动作。

几何支持、离散变换、细长计数、占优地面及周期可见性都是手工提供的归纳偏好。模型的能力范围由这些表示约束。本次正式结果覆盖一个原版游戏的七个关卡。 [空间学习](../../../julia/TddESCat/src/SpatialLearning.jl) · [视觉表示](../../../julia/TddESCat/src/VisualFields.jl) · [条件归纳](../../../julia/TddESCat/src/ContactLearning.jl) · [规划与实验](../../../julia/TddESCat/src/VisualControl.jl) · [遮挡与时序](../../../julia/TddESCat/src/SceneMemory.jl) · [反向条件验证](../../../tests/julia/spatial_learning.jl)

## 从反例到下一次控制

下表的命令标识对应运行目录 `public/checks/<命令>.json` 和 `public/predictions/<命令>.json`。支持掩码在统一的像素矩形中编码占据位置。晋级回执中保留了同一步的中间帧，可同时确认落点和公开进度变化。

| 命令 | 实际证据 | 对后续控制的作用 |
|---|---|---|
| `c000000013` | 第一关，颜色同为 9，支持掩码 335 和 359，接触受阻 | 排除只靠颜色相同或无条件接触的解释 |
| `c000000026` | 第一关，试探图案变换后两侧支持均为 359，颜色同为 9，进入并推进 | 第一次取得公开正例，下一关以已有正反证据选路 |
| `c000000128` | 第二关，使用前一关的证据判断接触可行，实际进入并推进 | 在新位置消费前一关学到的条件 |
| `c000000160` | 第三关，两侧支持均为 461，颜色分别为 12 和 9，接触受阻 | 排除只要求支持相同的解释 |
| `c000000231` | 第三关，经过新的交互后两侧支持均为 461、颜色均为 9，实际推进 | 消费收敛后的条件，并核对新回执 |
| `c000000329` | 第五关，形状与颜色均不同，候选模型预测受阻，实际试探确认受阻 | 为已学条件增加异位对照 |
| `c000000429` 和 `c000000498` | 第六关，第一个接触确认进入，稍后另一个接触确认推进 | 规划先记录已进入的位置，再依当前画面和剩余资源继续寻找有证据的接触 |

对 `c000000231` 冻结的三个代表样本做离线重算。保留全部样本时兼容条件有 4 条。分别移除两个受阻样本后，各自对应的组合由确定受阻变为未知。移除代表正例后，相合组合由可行变为未知。

末关的 `c000000529`、`c000000541`、`c000000545` 记录了颜色从 12 到 9、从 9 到 14、再从 14 到 8 的确认效果。`c000000531` 记录了保留颜色的形状变化。决策记录把这些动作标为待验证效果的实验。`effect_gain` 表示此前观察到可改变的特征中，有多少可能解除当前候选条件中的不满足项。程序据此选择继续试探的局部效果，路线随反馈更新。

| Julia 空间与关系学习 | 从帧差学受控角色、实测位移及局部效果，由接触模型筛选可行条件，由视觉规划器产出具体动作，并在反馈后修订状态和重验余下路径 | `spatial_experiment`、`spatial_feedback`、`contact_feedback`。 [正式入口](../../../julia/TddESCat/src/OnlineSession.jl) |
| Catlab 范畴框架 | 在效果语料构造中，检查带属性 C-集合（Attributed C-Set，ACSet）结构映射的自然性，再用推出沿同一动作事件组合多个前后角色。首批动作 `c000000003` 的两个位移和一个计数效果形成角色顶点 `[[2,3],[4,5],[6,7]]`，共享事件顶点 1 | `public/learning/job-000001/observations.json` 的 `catlab_event` 和 `catlab_role_vertices`。 [范畴实现](../../../julia/TddESCat/src/CategoryBackend.jl) · [语料构造](../../../julia/TddESCat/src/LocalEffects.jl) |
| Rust E-Stitch | 对当次公共效果表达执行实际结构搜索，衡量包含库代价的净收益，原子保存轮次并在下一批续用已验证库。首批从空库接受两个定义，三轮后费用由 110 降到 72 | `public/learning/job-000001/output/`。 [Rust 搜索桥](../../../rust/bridge/src/engine.rs) |
| Julia 编解码与结构消费 | 编解码（Codec）负责跨语言表达和证明的解析与核对。Julia 独立回放匹配、参数和展开来源，通过后发布并重读结构，在实际动作前生成附带定义引用的联合预测。首个签收例 `c000000014` 引用深度 1 的定义，两项位移预测均得到回执支持 | `public/publication/`、`public/checks/c000000014.json`。 [编解码与证明](../../../julia/TddESCat/src/StitchCodec.jl) · [联合效果消费](../../../julia/TddESCat/src/JointMechanisms.jl) |

路线选择的直接证据是视觉计划及其读取的早期动作。正式任务的学习意图是 `effect`，消费入口是 `joint-mechanisms`。Catlab 为同事件效果建立可组合的角色接口，E-Stitch 将这些表达压缩为可复用定义，Julia 把经验证的定义用于动作效果预测。首批的费用是表达描述成本。匹配费用沿用 E-Stitch 的因子化实现。本次证据覆盖单次动作的联合效果结构及视觉计划，树决策图、多值决策图和跨动作程序抽象的结果适用各自的验收。 [因子化费用实现](../../../third_party/egg-stitch/src/cost.rs)

架构作用的证据来自这些调用、产物和消费者。此次度量覆盖各模块的实际调用及消费，对各模块独立的通关增益未作估计。
