# 从公开回执学习对象边界和位置之间的内容对应

## 模块接口

`EndpointTransforms.jl` 使用同色四连通分区中的实心矩形。每种变换负责从前后两帧提出实例、在动作前绑定输入并预测可观测输出、在动作后独立核验和细化。新增变换可在 `endpoint_examples` 注册。当前实现只对确认动作的首末画面作局部判断。

边界模型保留颜色及三条固定边，学习第四条边的有符号位移。比较变化带中原有的同色像素，可以排除吞并另一同色区域或分裂产生的伪伸缩。点击角色与受影响区域允许分开，在新位置可用相同点击部位与相对几何位置重新绑定。

位置内容模型将同尺寸、位置固定的多个区域看作一组待验证的对应。每次观察用各位置的前后颜色细化来源类和目的类。各类两侧的个数必须相等，才存在符合全部已读观察的一一对应。预测只覆盖所有可能来源对当前颜色达成一致的位置。一条动作只贡献一次回执，同一画面的多个位置属于同一次试验。

`TransitionExperiments.jl` 管理候选、版本、证据和实验。首次观察可以提出实验，当前已知的动作也可以在其他任务选中它时附带检验。任务议程按原入口仲裁，状态在确认回执后更新。反例收窄到有正例的输入，同一输入有冲突时进一步限定到有支持的画面条件。终态、换关和画面尺寸改变保留未决。完整画面中的其他残差独立保留。

## 验证

构造测试覆盖异地点击引起的对象伸缩、干扰像素、同色区域合并、换位置绑定、反例收窄、非环形排列、重复颜色、无变化和终态。依次经过正式的关系仲裁、预测生成及回执反馈函数。

真实数据取自 82 原生运行 `public25-native-2c87e7ed` 的确认事务前缀。回放从第一条 RESET 开始，以旧版已选动作作为输入。每步生成局部预测后才解码该步回执，同时核对来源顺序、命令与响应哈希。另以 Python 直接检查原始像素、边界及变化带。

| 公开回执前缀 | 核对结果 |
|---|---|
| s5i5，2,048 条 | 四个已识别控制点上，竖条伸长 134 次、缩短 153 次，横条伸长 15 次、缩短 28 次，共 330 项预测得到支持。变化量均为 3 像素。另有 6 项未决。 |
| lp85，180 条 | 第一关对全部 20 个槽位有 1 次完整预测得到支持、1 次未决。第二关对全部 42 个槽位有 17 次完整预测得到支持。两关分别另有 3 次和 2 次部分槽位预测得到支持。 |

上表的计量单位是特定关系的事前预测；同一动作可能还检测其他关系。此回放沿用旧动作，通关与自主动作选择的实测需读取新版运行回执。可以对其他公开运行使用同一入口，第二个参数为回放事件数。

```sh
julia --project=julia/TddESCat tests/julia/endpoint_transforms.jl
julia --project=julia/TddESCat tests/julia/replay_endpoint_transforms.jl PUBLIC_DIR 2048
```
