# 同色四连通区域先验与统一代数 Grounding 修订

2026-11-26 10:51（台北时间，星期四）｜理论与实验计划修订，非仓库实施记录

本文补充同目录 `01-统一代数Grounding与动态因果抽象实验计划.md`。对于初始变量、结构发现顺序与实验对照，以本修订为准；原文的公开接口、证据责任、完整历史、两个里程碑及性能验收原则继续有效。

## 1. 裁决：区域是首选结构变量，像素是不可丢失的事实

ARC-AGI-3 输入具有已知二维网格拓扑及离散颜色。同色四连通分量（Same-Color Four-Connected Component）是精确计算的初始区域，而不是先训练统计模型才能发现的结构。对有效公开帧全域进行分区，所有颜色（含 0、可能的背景、界面区域、单像素）一律保留。不存在按面积或颜色先排除功能对象的依据。

定义 E(p,q)=[F(p)=F(q)] AND [曼哈顿距离=1]。对 E 求含自身的可达闭包，其等价类是唯一的极大同色四连通分量。它们构成满足这些限制的最粗分区。用一次网格扫描及广度优先遍历或现有等价的线性算法即可完成，无需构造像素两两关系矩阵。八连通是四连通的粗化，可由四连通区域间对角接触求同色闭包，不能视为所有功能对象的真实边界。

基础区域是单帧精确事实，功能对象是跨帧及动作语义下可修订的假设。禁止把两者的身份、颜色相等或几何连通直接视为因果等价。区域编号限定于具体帧；对象身份需要跨帧对应证据。不能假定同色接触导致错误的频率已经得到实测。

## 2. 从第一帧开始的代数计算

令 p 为位置、r 为基础区域、c 为颜色；U(p,r) 为成员指示，V(r,c) 为区域颜色指示。B(p,c)=OR_r[U(p,r) AND V(r,c)]，可以精确恢复所有位置颜色。U 是确定的成员关系，并非待拟合的潜变量。V 为每个区域恰好一种颜色。实际保存紧凑区域索引及精确像素集合，原始帧与可逆记录仍须可回读；无需建立稠密 N×m 矩阵或重复事实库。

令 J(p,q) 为四邻接，接触关系 A(r,s)=OR_{p,q}[U(p,r) AND J(p,q) AND U(q,s)]，忽略自环后即区域邻接图。采用自然数半环可计算实际共享边数；采用布尔半环计算是否相邻。二者含义不同。可在扫描水平/垂直网格边时直接构造稀疏关系，无需计算稠密乘积。区域面积为成员集合的计数；形状、边界、相对位置及包含等保留可计算定义，按需要产生，而不是手写固定游戏属性模板。

采用区域作为候选检索和关系组合的起点，不把区域编号当作跨帧统计变量。对象可为区域的并、子集或多色/不连续组合；区域内像素仍可按需绑定。功能对象的候选可以重叠，不强制成为单一全局分区。区域邻接图也不限制远端因果依赖。

对于固定有限关系，Factor Rank（因子秩）和 Algebraic Tree Decision Diagram（代数树决策图）提供精确切分秩、规范化及组合查询。注意位置—区域成员矩阵 U 的非零列两两不交，其有理数矩阵秩恰为区域数；区域分解不等于低秩，不要求每个简单区域掩码编译成电路。按真实查询测定不同变量树、共享结构、编译与增量成本。原论文 Rust 原型的全真值表式任意变量树转换仍不得直接进入大域热路径。

Probabilistic Circuits（概率电路）优先学习区域描述、跨帧对应、作用条件、区域共同响应和竞争对象解释等不确定关系。不要重新学习已经确定的同色、邻接、成员事实；不要把可变的区域编号直接对应到固定模型的永久变量。概率电路中的 Region Graph（区域图）是变量集合分解结构，与图像空间区域图不等价；可以由真实依赖选择其组织方式，不预设局部区域因果独立。Tensor Factorization（张量因子分解）在区域关系、时序变化和完整定义的转换候选上研究共享因子，不把低秩补全写回观察事实。

## 3. 区域层的反例驱动对象语义修订

基础分区每帧重新由观测定义，历史分区不可被假设修改。对象层维护带证据的候选成员、对应、参数化结构及机制适用域。跨帧关系不强制一一匹配，允许一对多、多对一、多对多、消失、出现、遮挡和身份不确定。重叠只是候选线索，不等于对象同一性。

初始对象候选取每个区域，不立即枚举全体区域子集或每个像素的任意组合。用真实差异、边界、已有对应、共同/差异响应、残差与高阶依赖产生候选。每次出现反例时，先定位预测与观测的具体不一致位置和效果关系；再同时检查绑定错误、区域内部不同响应、多区域联合、隐藏历史状态及机制条件不足。只有具备区分证据时才承认某一对象解释，不能根据单次视觉分裂就断言两个真实对象。

- 向下精化：同色区域的一部分与其他部分持续存在不同的动作响应时，从精确像素集合及跨帧对应提出子结构。保留原区域分区，更新对象解释及依赖版本。
- 向上组合：多个不同颜色或分离区域在不同上下文中具有一致的联合变换或因果响应时，提出组合对象；不因单次共同变化直接认定属于一个对象。
- 时间修订：相同画面、不同历史产生不同响应，优先研究 Predictive State Representation（预测状态表示）及历史条件，而不是无意义地切碎空间区域。

新对象定义须能从原始公开观测回读其成员并在当前状态重新绑定。旧假设被反驳后，使相关统计、关系、程序等价、缓存与已编译结果失效，精确复核受影响的完整历史；保留原始事件。概率分裂合并可提出候选，但不是删去低频因果证据的机制。

## 4. 修改后的计算与认知架构

公开网格/动画帧 → 精确同色四连通区域与空间关系 → 跨帧对应/变化/对象候选 → 对象—动作—条件—效果关系 → 抽象与机制程序 → 预测、真实控制及反馈。

类型化关系、张量与代数计算作为贯穿各层的共享服务，而不是区域生成后才出现的第二套世界模型。共同基础：Product（乘积组合）、Aggregation（聚合）、Elementwise Mapping（逐元素映射）、类型化重索引/条件化以及必要的不动点。多维偏序组织条件包含与对象集合细化；Factor Rank 优化精确函数表示；布尔因子分解提出共同属性；概率电路管理不确定响应；反统一、归纳逻辑程序设计与 E-Stitch 从已经形成语义的关系/程序进入；范畴组合检查机制接口及结构保持。以上学习与验证职责不由一次张量收缩自动完成。

基础区域分区的确定性、高层模型的语义假设、概率评价、证据及控制策略必须分开。坐标点击 ACTION6 的可用参数域不能缩成一个区域一个代表点；同一区域内部不同坐标可能具有不同功能。空间分区用于组织测试，不作为相同动作效果证明。ACTION1–7 按实际公开可用性与参数覆盖；ACTION7/RESET 单独记录。禁止读取调试或私有状态。保留所有返回的动画帧及公开状态变化，不能把无可见变化直接解释为无作用。

## 5. 两个里程碑的具体修订

### 里程碑一：区域先验与统一代数计算的精确性、净收益

A：冻结现有生产 Grid64/Grounding；先查真实代码是否已经有同色四连通算法，避免把既有能力当作新增创新。B：同一真实接口和事实下，将区域设为统一关系查询的默认结构变量，精确像素可回读；复用原有正确的位集合和连通原语，生成稀疏区域关系。C：B 加入明确查询类别的精确因子化及 ATDD。三者为独立实验，不是备用路径。若基线已有区域分解，实测差异必须来自计算组织、复用、对应及语义责任，而不是虚构区域与像素的对比。

算法：

```text
for every public frame in observation:
    regions = label_same_color_four_connected(frame, include_all_colors=True)
    verify_exact_partition_and_reconstruction(regions, frame)
    spatial = compute_sparse_region_relations(regions, frame)
    delta = exact_pixel_and_region_changes(previous_frame, frame)
    correspondences = generate_relational_candidates(regions, history, delta)
    query_results = evaluate_typed_relations(spatial, correspondences)
    record_dependencies_and_real_cost(query_results)
    deliver_to_existing_production_consumers(query_results)
```

独立裁判验收：全像素覆盖、互斥、同色、四连通、极大性、逐像素重建零差异；区域关系与像素直接计算相等；四连通到八连通粗化等价；分裂合并及局部颜色变化后的增量结果等于完整重算。单像素、全同色、棋盘格、相邻同色、异色接触、对角接触、环及孔洞、背景变化、多动画帧及边界条件均需覆盖。

性能测试：真实公共轨迹上报告每帧区域数 m/N 的分布及异常情况；固定同输入、同查询、完整历史及同责任，报告构造、对应、绑定、编译、查询、更新、内存和端到端耗时。m=N 的棋盘格是最坏情况，不能承诺普遍压缩；不得以省略背景、像素内作用域、跨区域依赖等取得假加速。精确层验收零差异且新接口有真实调用者。性能无净收益时 H2 不通过，不做结论粉饰。

### 里程碑二：由区域到动态因果对象与抽象控制

D：固定初始区域为对象候选，不允许语义精化的消融对照。E：区域作为初始候选并支持证据驱动分解、组合及跨帧对应修订。F：E 加入概率/布尔因子与动态响应学习；分别记录其新增贡献。所有正式候选不限制为连通单色对象。合成环境真值仅供独立裁判，不进入算法；真实 public25 严格公开接口，同样完整动作覆盖及历史责任。离线按时间先预测后读结果，不能用未来帧训练过去模型。

必须验证：同色接触后分别响应；多色对象共同运动；空间分离部分联动；视觉分裂但对象语义不变；相同区域内不同点击作用；同画面不同历史；高阶条件（包括异或）；远端/延迟效果；静态或无像素变化事件。要求反例驱动语义修订，并使后继动作实际使用新模型。合成真值和真实可验证证据分开评价。

指标：对象成员/跨帧对应正确性；未解释变化；已支持、已否定、证据冲突、未辨别四态覆盖；动作及坐标类覆盖；预测校准、稳定性、语义绑定和多步控制；每单位时间有效交互、实际计算及复用。只有在声明可观察/可达范围内证据充分时才报告动作—对象最小因果单元闭合。原实验计划的 H1/H2/H3 保持独立。禁止因普通随机波动对单款游戏成绩过度归因。
