# ARC-AGI-3：从原始数据到统一代数 Grounding 的验证计划

2026-11-26（台北时间，星期四）｜研究计划，未执行仓库修改或真实游戏实验

## 1. 目标、依据与边界

研究目标：从公开原始网格、动作及实际响应开始，利用张量、关系、代数电路及概率电路发现计算结构，在保持原始事实和必要控制区分能力的前提下，逐步形成可绑定的关系、对象、概念和机制。验证能否简化算法实现、降低实际闭环重复计算及重复学习。

三个待证伪假设：H1 兼容的类型化关系函数语义可贯穿各层；H2 公共算子与共享执行结构可获得端到端净收益；H3 底层分解与动态响应学习能产生有意义的语义提升并改善控制。H1、H2、H3 分开裁决。任何一种表示更小、预测似然更高或少数通关结果更好，都不单独证明三个假设。

现有仓库代码尚未在本轮读取。实际文件位置、生产入口、配置及分支必须由 Codex 在修改前阅读 `docs/changelog/` 中现行计划并追踪真实代码确认。本文的函数名是建议接口语义，不是对当前源码位置的声称；不要据此新增一批相互独立的事实库或固定游戏模板。

严格公开应用程序接口（Strict Public Application Programming Interface）：只读公开返回的网格、动作可用性、实际动作参数、合法公开状态/进度。禁止私有游戏状态、源码机制、调试元数据、正确对象/解法标签进入求解路径。合成环境的真值只用于隔离的测试裁判。ACTION1–7 按实际公开可用性覆盖；ACTION6 记录公开显示坐标及其到内部表示的映射，坐标不可靠时不将猜测映射作为已证实知识；ACTION7 与 RESET 等生命周期/逆向操作单独记录和评估，不与普通正向作用机制混算。实际动作语义以实验为准，不根据编号预设方向、对象或功能。

所有运行配置使用配置文件；保持现行默认或更充分的学习/计算设置，不通过人工缩小候选域、删除历史、降低覆盖或降低质量来制造加速。不引入旧版兼容 fallback；实验对照是独立、显式选择的配置，不是生产备用路径。

## 3. 最小共同语义与计算接口

### 3.1 事实、函数、知识版本

每次公开交互保存：实际收到的前序及后序全部网格/动画帧，执行动作和参数、公开可用动作、会话/关卡进展信息（仅在接口提供时）、观测顺序和关联证据身份。原始事实不可因模型修订而删除。已知帧中的所有位置有准确颜色；未观测的可能状态转换不能当作已知负例。

以有限类型化函数表达查询。每个函数的变量及定义域（如位置、颜色、时间、候选对象、动作参数、效果），值域（布尔、自然数、精确有理数、非负概率因子等），已知/未知范围，数据和规则依赖版本必须明确。一个候选对象的成员关系、属性关系、效果关系可以指向同一事实来源；不要求固定对象类别，也允许对象候选重叠、不连续、分解/合并。

对于未完全确定的布尔关系，记录已经确定的真/假范围以及剩余未知域；冲突证据先保持冲突而不是强制合并。低秩补全是候选模型，不得写回观测事实。对于确定的单次事件，可以检查其完整可见变化；不能把这一观察外推到其他上下文。

### 3.2 基本算子

Functional Aggregate Query（函数聚合查询）形式：Q(X) = ⊕_Y ⊗_i R_i(V_i)。X 是输出变量，Y 是消去变量，R_i 是输入关系，V_i 是其涉及的变量。

建议仅保留必要的核心接口：

- `product(f,g)`：以同类型、同身份的共享变量对齐，按明确的半环乘法组合，不删除共享变量；例如连接成员与颜色关系。
- `aggregate(f,Y,semiring)`：消去 Y，按同一半环加法聚合；例如存在性、计数、边缘化。
- `map(f, mapping)`：显式映射值域；记录零保持性、是否保持运算以及本次转换的充分条件。一般否定、除法等操作需单独定义，不直接冒充 Atlas 的零保持映射。
- `reindex/condition(f, binding)`：类型检查后的重命名、坐标变换、切片及条件约束。保留绑定依据；不能将不同语义的同名变量误接。
- `least_fixpoint(seed, step)`：对有限域的单调关系迭代到不动点；不把所有递归都展开为一个稠密张量。

精确布尔查询、自然数计数、有理数计算、概率因子计算是不同语义。尤其先布尔存在量化再数不同结果，与直接数见证路径不同。最大化与求和一般不可交换。未知域需保留约束相关性，简单上下界传播只给安全界而非所有情况下紧界。

底层执行优先保留紧凑位运算、稀疏关系及因子结构；对完整定义的函数可按固定变量树编译 ATDD（Algebraic Tree Decision Diagram，代数树决策图）并比较精确表示。概率电路只存模型分布与统计，不是事实权威。编译结果记录语义/依赖版本及适用范围，版本改变时必须使相关查询结果失效并重新计算。

每一项计算先检查变量类型、域和代数合法性，再根据表达结构执行。监测中间节点数、切分秩、系数位长度、稀疏性与真实分配。Atlas 的平滑、可分解、兼容、确定性及映射条件按每次组合结果重新检查。未满足理论条件不能宣称多项式保障；不得悄悄删候选或改写语义来保证运行。

## 4. 里程碑一：原始数据到精确统一关系计算及可验证压缩

### 4.1 入口与基线冻结

先查现行公开入口、Grid64 底层、候选构建、联合绑定、历史复核、持久化及动作回路。记录生产函数路径、调用者、输入输出语义、配置文件、提交及测试版本。分析现有瓶颈而非只依据 changelog。基线冻结原生产路径；若该路径不能运行，明确记录阻塞，不虚构性能。

三个独立实验配置：A 原生 Grid64/关系计算；B 共享类型化代数语义、位集合/稀疏执行；C 在 B 的同一语义上增加精确因子化和 ATDD 对照。小规模稠密真值表仅作独立测试裁判，不是生产备用路径。对于 C 的张量或电路后端单独记录转换开销；Factor Rank 原型中完整真值表式任意变量树转换不得直接用于大域热路径。

### 4.2 算法落实

1. 从完整观测构建颜色指示 B(p,c)=[F(p)=c]。同色关系为 OR_c B(p,c) AND B(q,c)，邻接由坐标确定，与同色关系相交。连通用位集合传播或稀疏不动点实现。
2. 从前后帧构建 D(p,c,c')=B_t(p,c) AND B_{t+1}(p,c') AND [c!=c']；记录全部变化及完整原始帧，可逆回读。多动画帧的中间变化保留顺序。
3. 从实际差异和关系产生候选集合/对应，利用通用类型化坐标、集合及关系映射（例如关系同构、相对坐标、映射组合）生成绑定。不能先判断游戏类别再调用专用答案算法。对重合关系同时评价变化匹配、静态一致性和未解释残差；保留竞争解释。
4. 对完全已知的有限查询函数选择变量切分（空间、交错坐标、颜色、时间/事件或数据依赖分区），实测切分秩和电路规模。单帧64×64、16色条件下，坐标索引函数有12个位置位+4个颜色位；验证全部65,536种输入。注意这是索引查询函数，而不是4096个像素随机变量的联合分布。较大关系按完整有限测试、独立因子/位集合裁判及等价证明分层验证，报告没有穷举的范围。
5. 对对象候选与已计算属性的关系做 Boolean Matrix Factorization（布尔矩阵因子分解）：仅在已知真集合内产生候选因子；未证实外推单独标为假设；保存能够重建原关系的精确残差/表示。相同定义域下比较布尔因子覆盖与有理数秩的区别。概念提升先不改变事实权威。
6. 执行增量更新：依据发生变化的变量及版本传播到相关查询；结构重组后验证新表示语义。保持完整历史计算责任。把核心操作接到当前生产路径的真实调用点，不能只做独立演示库。

伪代码：

```text
observe = public_observation()
facts = exact_relations(observe, previous_observation)
for query in required_grounding_queries(facts):
    verify_types_and_domain(query)
    expression = compose_product_aggregate_map(query)
    evaluate_using_selected_experimental_backend(expression)
    check_result_against_independent_oracle_on_declared_test_domain()
    record_dependency_and_cost(expression)
candidates = derive_sets_correspondences_and_shared_factors(facts, history)
retain_exact_evidence_and_residuals(candidates)
return_grounding_to_real_consumer(candidates)
```

### 4.3 合成验证（裁判真值不可进入学习路径）

设计一组小有限域公开环境，按数学性质生成参数变化与重排列，而非写游戏攻略：同色不连通/异色联合、对象平移或其他坐标变换、形状或颜色参数变化、重叠候选、分裂与合并、远端依赖、无可见变化、多个见证路径、缺失/反例、动画中间变化、点击坐标及逆向/生命周期动作。对小域枚举所有公开可达到的状态/动作（裁判单独构建）；生产只通过同一公开适配器获取证据。另设完整布尔函数测试组验证 ATDD 精确规范化、同函数同变量树的一致性以及不同变量切分。

逐项断言：原始帧回读一致；关系与独立裁判一致；计数语义正确；已知负例未被因子覆盖；未知未被宣告为负例；上下文版本改变后缓存不陈旧；任何已认证的等价转换不能改变函数输出。对象对应在存在歧义时应保留候选，不能靠错误唯一化通过。

### 4.4 真正性能验收

同一已记录公开轨迹、同样查询、完整历史、候选域及输出责任下，比较 A/B/C。固定输入版本、硬件、线程和配置；分别测冷启动及热循环。记录：

- 表示总字节（含原始数据、索引、系数位长度、缓存、运行时中间值）、最大内存及分配；切分秩、节点/边/张量元素是解释指标，不替代实际内存。
- 原始关系构造、候选生成、绑定、分解/编译、查询、增量更新、完整历史复核、跨语言/序列化以及整个观测处理的 wall-clock；报告 p50/p95 和分布，而非仅快例。
- 重复查询的收益及编译成本，明确在多少次真实复用后有净收益。对相同查询负载，若 t_A>t_C，静态构造差额的回收次数约为 (C_C-C_A)/(t_A-t_C)；实际还应计入更新/重组。若查询不更快或现实复用不足，不能宣称加速。
- 功能统一程度：盘点真实消费者调用的语义运算及专用重复实现，检查原始关系、对象属性、机制绑定和程序组合是否真正经过共享核心；不能仅通过减少文件数量宣布算法简化。

通过门：已声明有限域的精确测试零语义差异、无证据缺失；生产消费者确实使用新接口；能够列出具备净收益的计算类别及无收益类别。若 H2 失败，保留失败结果，重新审视表示及分解策略；不把性能弱的实验实现强制进入生产。完成本里程碑代码时应提交并 push 明确分支和对应日期中文 changelog。

## 5. 里程碑二：因子驱动的动态状态、抽象机制与真实行动闭环

### 5.1 基于真实事件产生新因子和状态变量

在里程碑一的精确 Grounding 上，构建以事件/历史、当前对象或集合、属性/上下文、动作及实际效果为变量的部分关系。使用布尔因子发现共性、有理数切分秩压缩完整已定义函数、概率电路学习条件响应与不确定性。三者不同，不把负系数当成负概率。不要把某个因子强行当作最小因果机制。

用以下来源产生依赖候选：空间关系、跨帧共同变化、可计算参数/对应、条件响应差异、预测残差和高阶组合。两两互信息仅用于候选提示，不能成为排除高阶机制的唯一依据；XOR 合成例应检验这一点。新的变量及谓词必须能绑定到原始公开数据/历史测试，并解释产生依据。

当概率电路分裂或合并时，明确其操作是否保持当前分布、是否改变拟合的模型、哪些历史统计失效。旧历史重新查询用于精确受影响统计；不依赖论文近似恢复高阶统计作为确定因果证据。支持版本和依赖更新；已发生反例不得随概率权重降低而消失。

### 5.2 动态低秩学习及对照

定义 Predictive State Representation（预测状态表示）：D(h,τ)=P(观察到测试指定结果 | 历史 h, 执行测试指定动作序列)。h 是实际公开历史；τ 是可执行的动作序列和可观察结果条件。矩阵存储已实际取得的证据、样本数量及不确定性，未测试项明确未知。

基于可获得的历史与测试选择响应基底，用 Hankel Matrix（汉克尔矩阵）和谱分解产生 Weighted Finite Automaton（加权有限自动机）/预测状态更新算子候选。低秩基底的坐标不是语义对象。校验更新后的预测分布非负、归一化、与实际可达历史一致；出现负概率或归一化失败，记录该模型不满足概率语义，不靠静默截断冒充正确。

Dynamic Sum-Product Network（动态求和乘积网络）作为另一种共享时序模板的对照，在相同数据和预测任务下比较。TT-Cross（张量列车交叉近似）仅引导测试选择：无法到达或未执行的状态元素不能获取或补为事实。根据样本与可识别性报告估计秩/完整已知子矩阵秩下界，不宣称已知道真实系统秩。

当两个历史最后一帧相同但后续测试响应不同，必须保持区分；当两个历史已有测试响应相同但还有未测试分歧，暂时合并只能作为可撤销假设。不同对象/状态的响应比较要保留动作参数、上下文和可能的延迟效应。

### 5.3 从关系提升为概念与机制

候选语义定义由可计算成员/关系、变量域、对应绑定和证据支持构成。多维偏序用于组织明确的蕴含、泛化、具体化与接口映射；变量树用于计算分解；证据图用于推导追踪；概率权重用于不确定性，不能混成一个图语义。

对已经形成的适当关系层，使用反统一、动态谓词发明或 E-Stitch 学习可复用表达式/程序（这些不是必须全部串行运行的阶段）。不得在 ILP（Inductive Logic Programming，归纳逻辑程序设计）中暴力从全部像素枚举规则；缺失条件通过高层预测失败定向请求底层精化。

机制需提供可执行条件、动作和效果关系、版本以及证据适用域。对有限模型中的抽象 α 和对应动作/接口，检验：α'(T(s,a)) = T_bar(α(s), a_bar)。概率机制比较映射后的下一状态分布与抽象模型分布；这要求抽象动作可绑定，比较同一作用语义。上述是借鉴因果与组合抽象论文提出的工程检查，不是其完整定理的替代。模型内检查与真实公开干预结果分开。还需检查被抽象丢弃的状态、终止/进度、目标与多步后续控制差异。

### 5.4 下一动作真实闭环算法

```text
repeat while public environment permits interaction:
    append all actual public evidence
    update exact relations and their dependencies
    obtain candidate shared factors, bindings and states
    revise structure and model hypotheses on residual or counterexample
    recheck affected historical evidence and invalidate stale compiled results
    build executable action/transition predictions for current bindings
    enumerate publicly available actions and applicable parameter bindings
    predict effects and identify unresolved distinctions among hypotheses
    choose a reachable, informative experiment or goal-directed action
    record predicted effects, active assumptions, and reason for choice
    execute through the strict public interface
    observe actual response, including animation and progress if public
    compare prediction with observation; update hypotheses/relations
    compile and reuse only definitions whose required semantics were checked
    demonstrate that revised knowledge is consumed by subsequent action choice
```

选择有辨别价值实验可以使用竞争机制预测分布之间的差异，例如对假设权重 w_i 和合法可达候选测试 a，计算 ∑_{i<j} w_i w_j TV(P_i(E|h,a),P_j(E|h,a))；TV（Total Variation，总变差）衡量两分布差异。该值只是实验排序的一种候选，不替代真实可达性与目标控制，不以虚构的未观测概率硬性删除候选。动作实际执行结果必须进入修订，并改变后继预测或策略（必要时通过同状态受控对照证明选择差异）。

### 5.5 实验对照和防泄漏

先用相同合成公开任务和固定公开交互轨迹，对照 D=里程碑一的确定性关系及现有机制学习基线；E=D+底层布尔/概率结构学习；F=E+历史动态响应模型和反例驱动精化。动态学习器的 WFA/PSR 与 DSPN 独立配置比较，不强行重复学习两套知识。再进行 public25 公开真实闭环试验；沿用现行合规配置和完整动作覆盖责任。所有比较先冻结代码、硬件、配置、可用证据和初始条件。

离线只用轨迹前缀学习，并在看到下一事件之前保存预测；后续公开轨迹按时间/关卡作为留出，防止同一帧或未来证据泄漏。不能从离线轨迹宣称未执行动作的实际效果。主动策略比较使用公开可用复位/初始条件或可比上下文；不可重复的情境报告配对不足，不假定游戏一定随机或一定确定。对真实游戏进程重点比较相同证据阶段的学习与控制质量，不根据不同 game 的普通小关数量涨跌下因果结论。

### 5.6 动作—对象最小因果单元闭合与性能验收

定义可核查范围：在公开观测和已发现变量下，所有可用动作、参数域、相关对象/集合及绑定、上下文、效果类型及延迟时间范围。对 ACTION6 完整公开参数域可用符号分区组织；每个合并类必须证明或验证同等机制/适用条件，否则保留细粒度未知。ACTION7 与 RESET 单独记录，不视作普通动作效果样本。不得为降低候选数量随意预判动作无效。

对每个声明范围内的因果候选使用互斥状态：已支持且无冲突、已否定且无冲突、证据冲突、未辨别（其中可注明不可达/未取得样本）。分别记录覆盖的动作、参数类、对象绑定、条件和效果。检查即时、延迟、联合/远端作用，以及无可见变化是否仅为单次观察。只有范围明确、内部候选得到区分、证据和验证条件充分时，才能报告该范围的闭合；无法观察的隐状态或不可达上下文不能被宣称已完全覆盖。

验收指标：

- Grounding：合成裁判的成员、对应和属性精确性；真实轨迹中可验证的一致性、重建残差、歧义保留、反例改正率。
- 预测：逐步预先登记的变化预测精确率/召回率、效果关系错误、对概率预测的 Brier 分数/对数损失及按上下文的校准；多步预测和状态区分。单独报告缺乏样本的上下文，不将高置信度等同于完整覆盖。
- 因果：不同动作/条件的真实响应能否区分竞争解释，机制适用域稳定性，动作作用对象的验证比例，未闭合及冲突单元。统计按相互依赖的轨迹/回合聚类，不将连续相关帧当作独立样本。
- 控制：反例修订是否真正改变下一次预测及可执行动作；比较控制任务中目标实现、错误动作、可验证的多步机制复用及每单位时间有效实验数量。跨关卡验证对应机制语义，而非围绕随机结果波动过度分析各个游戏通关数。
- 效率：学习、预测状态更新、编译/重组、历史复核、查询、绑定、动作选择以及外部接口等待分项计时；比较实际端到端延迟、吞吐、内存及真实复用次数。用同数据同责任对照，不能降低覆盖、削减证据、放宽验证来换取加速。

硬门：无私有数据访问；精确层不发生语义回归；未知/冲突不被伪造为闭合；真实动作反馈进入模型且由下一决策消费；预先记录预测后才可读取结果。H3 还需观察到稳定的语义/预测/控制收益及至少一类重复学习或计算的净减少；若只有拟合或压缩改善、控制无改善，则 H3 尚未通过。效应大小及实用差异标准应在真实实验前以配置/验收文档声明，报告配对统计与不确定性，而不是实验后挑选成功样本。
