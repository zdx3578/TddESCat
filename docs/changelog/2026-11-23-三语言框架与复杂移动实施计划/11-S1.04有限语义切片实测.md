# S1.04 有限语义切片实测

Julia 现在能给公共帧中的像素、窗口和候选对应附上事件与坐标来源，识别四连通和八连通分量，在有界窗口内枚举完整支持，并保留碰接、裁剪产生的多个解释。Catlab 实际执行带类型对照的同态匹配、推出和自然性检查。类型项明确区分自由槽与定义参数，动作前检查会拒绝对未来证据的读取。

JULIA_DEPOT_PATH="$PWD/.runtime/julia-depot:$HOME/.julia:" \
