M01 的 3×2 定位例分别核对离开列、两列不变内区和进入列，另有 2×2、同色干扰和等外观交换对照。M02 检查整形状、孔洞、边界、凹口和视野外条件。三格目标与扫过配对使用相同起始帧及障碍 `(5,6)`。M13 检查裁剪前后四连通、对角的四八连通区别、多色整移和两个同色形状的接触再分开。

独立裁判直接枚举私有有限状态并转换为预期公开帧，环境进程由固定 ARCEngine 渲染。评分核对本地官方 HTTP 服务的完整响应。文件系统和进程命名空间的负测试验证环境包、私有场景、宿主仓库和环境进程不可读，私有 HTTP 路由返回 404。外层网络命名空间只提供本次回环服务。
