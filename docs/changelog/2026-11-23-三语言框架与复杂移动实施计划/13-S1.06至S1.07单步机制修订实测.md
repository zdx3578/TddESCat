# S1.06–S1.07 单步机制修订实测

从隔离环境的官方本地接口采集 8 次独立移动，Julia 从完整支持生成结构语料。真实 E-Stitch 将单位成本从 49 降到 31。Julia 验证并发布定义，从它读取位移表达、角色类型及事件来源，再通过同一证据事务冻结动作前预测。

M05 的手算、有限状态裁判及官方接口核对先通过。训练和反例在主体周围 7×7 个逻辑像素相同。首次 ACTION1 冻结预测位移 (2, 0)，回执给出 (0, 0)。修订保留该反例和后续解释义务，使旧版本的判断缓存失效，并从公开画面选出远端色块条件。下一动作改选 ACTION5，回执显示条件满足后再次选择 ACTION1，实际位移 (2, 0)。新位置的独立公开验证通过，面板裁掉时保留未知并保存决定。全程复用同一结构定义。

```sh
cargo build --offline --locked --release -p tddesc-stitch
.venv/bin/python -m tddesc_tools.run \
  --config config/acceptance/motion.toml --run-dir runs/s1.06-s1.07-motion-r02
```

`public/verified-motion.json` 汇总成本、事件、版本和动作，`public/control/checks` 保存预测核对和修订。另有 13 项三值条件、完整形状边缘碰撞、超出范围未知、同帧异历史判定的 Julia 断言。当前控制范围是单步、唯一支持绑定和已确认位移。位置留出处于同一颜色配置，完整参数文法、其它核心机制消费和保留种子矩阵仍需验收。
