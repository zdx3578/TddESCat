`config/sources.lock.toml` 记录各直接依赖的来源、版本、实际归档摘要及许可证。Rust 保留固定提交的编译源码和上游测试所用样本，根工作空间的本地 `[patch.crates-io]` 指向 `third_party/egg`。原 E-Stitch 锁的摘要和迁移说明见 `third_party/egg-stitch/UPSTREAM.toml`。两个 ARC 发布轮子的 `api.py`、`server.py` 和 `base_game.py` 分别与规格中的固定提交文件核对一致。

Julia 1.10.10 的 `Multispan` 构造在 Catlab 的推出调用中报 ``UndefVarError: `Hom` not defined``。去掉第三方依赖的最小构造器复现在 1.10.10 和 1.10.11 上同样报错，在 1.12.6 上成功。锁定 1.12.6 后重新生成 Manifest。JSON 选择 0.21.4，以满足 Catlab 拉入的 Compose 的兼容范围。Catlab、ACSets、GATlab、AlgebraicRewriting 和 HTTP 保留规格中的固定版本。ACSets 的包服务器归档未能取得，Julia 包管理器从注册表指定的仓库取到了 Git 对象。其树摘要 `068cdacaaf8f252596322521cc4808ab1f94ff8f` 与注册表和规格固定提交一致。

## 复跑

从仓库根目录运行。引导脚本需要 `uv` 和 Rust 工具链，优先选择项目内 `.runtime/julia-1.12.6/bin/julia`，也可用 `--julia` 指定同版本的安装。Linux x86-64 的 Julia 1.12.6 安装归档经官方校验表核对，SHA-256 为 `bbabf3bef19421a9dbd24a767d807606ab85e444323b5a1c73ffe293fa3d079a`。

```sh
python3 scripts/bootstrap.py --config config/toolchains.toml
.venv/bin/python scripts/check_sources.py --config config/sources.lock.toml
.runtime/julia-1.12.6/bin/julia --startup-file=no --project=julia/TddESCat scripts/preflight_julia.jl --config config/runtime.local.toml
cargo check --locked --workspace
cargo clippy --locked --workspace
cargo test --release --locked --workspace -- --test-threads 1
```

`bootstrap.py` 生成本机绝对路径配置 `config/runtime.local.toml`。本次验证日志在 `runs/`，包括启动预检、Julia 解析、Rust 编译及快照复跑。环境冒烟使用本地合成游戏和符号语料。

实际从仓库根目录执行 `bootstrap.py` 退出 0，Julia 的 30 项断言全部通过。Ruff、Python 字节码编译、`cargo check` 和 Clippy 通过。Rust 调试构建全量测试出现快照差异后中止。并行发布构建的快照测试为 131 通过、1 个搜索子进程失败，失败用例 `epfl::multiplier.factoring.live` 用同一发布构建单独复跑通过。发布构建串行全量复跑退出 0，132 个快照用例全部通过。上游 20 个语料重新生成检查因本地缺少 `.aig` 原始输入，按上游测试约定提前返回。
