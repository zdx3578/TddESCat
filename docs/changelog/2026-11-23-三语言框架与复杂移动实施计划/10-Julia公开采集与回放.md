# Julia 公开采集与回放

在已通过自检的 M01 公开 HTTP 环境上运行 Julia 只采集入口。环境和采集进程使用不同的文件系统与进程命名空间。Julia 通过公开列表确定游戏 ID，以已记录的探索策略从当前合法动作中选择一个动作，保存动作前预测占位和决策来源。

```sh
.venv/bin/python -m tddesc_tools.run --config config/acceptance/evidence.toml
```

`runs/s1.03-evidence-r01` 的 `capture_replay` 通过。官方服务器记录一次 `RESET`、一次 `ACTION1`，计分卡开闭另计。两个动作各保存一份完整 64×64 响应，公开原始字节的 SHA-256、请求摘要、动作回显、帧和事件链均可复核。独立裁判按完整形状验证。逐像素差异包含 16 个坐标，与手算的移出和移入边缘一致。

回放在服务已停止后的独立网络命名空间执行。第一次处理两个事件，第二次处理零个，处理游标和原命令记录一致。回放通过本地内容寻址响应重新验证身份和全帧，更新可重建索引和差异记录。

此入口使用显式 cooperative 配置。要求 cgroup v2 硬限制的公开配置需要相应的宿主监管支持。运行产物覆盖采集、恢复和差异查询，完整语义及学习由后续任务接入。
