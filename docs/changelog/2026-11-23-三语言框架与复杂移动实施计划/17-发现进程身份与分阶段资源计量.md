# 发现进程身份与分阶段资源计量

作业清单绑定上游版本、锁文件、本项目编译输入摘要和实际 Rust 二进制摘要。启动时可读取嵌入的编译身份，Python 独立核对本地输入和文件摘要。Rust 在隔离域内再次验证作业身份。发布产物保留所用引擎身份。

因子共享不可变行块。机器整数计数使用检查乘加，独立接口可以准确计算任意精度计数。无内部绑定者的适配配置保留搜索时的匹配快照，按块对当前规范编号执行受类型约束的应用。每块结束重建并复核分析。传统含内部绑定者的路径继续按原时机合并。

Rust 分阶段记录托管分配的实时与峰值字节，阶段包括读取、建图、搜索、应用、提取、证明、序列化和原子提交。工作进程同时有 cgroup 硬限额，进程 CPU 与峰值常驻内存保存在工作日志。托管计量涵盖 Rust 分配器的申请字节，硬限额涵盖更广的操作系统内存占用。

`runs/review-resource-r01` 的 50 项端到端断言通过。一行一块与 128 行一块得到相同的成本、定义、改写、证明和来源。8,192 字节托管预算明确停止。第一轮保存后耗尽步数仍可读取完整轮次。70 项 Rust 库测试通过，包含八个 256 行因子组合数为 2⁶⁴ 的边界。
