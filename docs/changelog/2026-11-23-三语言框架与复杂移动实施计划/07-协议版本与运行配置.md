# 阶段一协议与运行配置

S1.01 的协议文件位于 `protocol/v1/`。使用 JSON Schema 2020-12 构建离线验证注册表，按文件引用统一校验作业、签名、类型项、定义、轮次结果、公开事务、事件、预测、覆盖和验收。学习正文的 `Param` 与输入项的 `Slot` 使用不同的递归定义。公开事务文件保留请求正文和摘要，响应文件使用内容寻址。

结构约束由 Schema 验证。文件内容摘要、符号和参数绑定、证明引用、完整轮次发布以及命令和事件一致性仍由各自运行边界检查。作业清单只允许声明的文件引用及学习版本字段。

`config/real_public.toml` 保存公开收集和后续学习的配置合同。`config/bench_agent.toml` 是本地验证的公开配置模板，私有场景配置由测试侧使用。凭证样板位于 `config/secrets.local.toml.example`。Julia 从配置文件自身的位置解析相对路径，并拒绝未知字段、版本、重试和重定向的无效设置。

运行 `.venv/bin/python -m tddesc_tools.contracts` 可验证全部 Schema 和文件引用。回归测试检查学习版本、相对路径、自由槽泄漏、点击范围和验收字段。Julia 的配置测试同时验证公开和本地配置，并覆盖未知字段和错误的动作提交策略。
