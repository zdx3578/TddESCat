# 公共协议故障验证

使用项目 Julia 客户端连接本地故障代理。代理将正常请求转发给固定版本的官方 ARC 工具包。已验证请求正文、坐标和响应身份、会话 cookie、公开动作域、全帧保存以及本地恢复。

```sh
.venv/bin/python -m tddesc_tools.run --config config/acceptance/protocol.toml
```

验收运行 `runs/s1.02-protocol-r02` 的 P01–P08 共八项通过。公开结果见 `public/acceptance.json`。每个子例附命令事务、响应摘要及事件文件，独立代理记录只在测试侧。

- P02 的丢包和超时均在后端已执行后注入。已接受动作各为一次，结果记为 `outcome_unknown`。
- P03 的前、后执行 400 使用完全相同的公开响应正文。客户端均隔离会话。非法本地命令的请求计数为零。
- P04 的三帧保留中间变化。后一条非矩形响应未产生确认事件。
- P05 分别替换实际另一会话的响应、动作回显和点击坐标。P06 分别丢弃计分卡开卡与首次重置回执。
- P07 在已确认、已落盘回执及仅已标记发送三个时点终止 Julia 进程。离线复跑验证事件身份、处理游标与网络调用计数。
- P08 验证下架动作不能从旧的合法动作域再次发送，缺失动作域使结果保持未知。

首次联调发现固定 HTTP.jl 在显式 `Client` 下禁止逐请求覆盖代理。客户端显式使用无代理的传输对象后复跑通过。此处的通过范围是协议故障场景。
